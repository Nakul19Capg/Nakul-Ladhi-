
# Hello World Java

A simple Java "Hello World" application demonstrating basic Java programming.

## Description
This project contains a basic Java application that prints greeting messages to the console.

## Files
- `HelloWorld.java` - Main Java class with the program entry point

## How to Run

### Compile the program:
```bash
javac HelloWorld.java
```

### Run the program:
```bash
java HelloWorld
```

## Expected Output
```
Hello, World!
Welcome to Java programming!
This is a sample Java application pushed to GitHub.
```

## Requirements
- Java Development Kit (JDK) 8 or higher

## Installation Instructions
1. Clone the repository to your local machine
2. Navigate to the project directory
3. Ensure Java is installed by running `java -version`

## Troubleshooting
- If `javac` command is not found, ensure JDK is properly installed and added to PATH
- Clear any existing `.class` files before recompiling: `del *.class` (Windows) or `rm *.class` (Linux/Mac)
